tool-schema-lint

Lint MCP tool schemas before your agent misuses them.

Agents call tools wrongly because the schema left room for interpretation. This checks the specific things that cause it: a missing description, an input nobody explained, an optional parameter with no default, a string that should have been an enum — and how many tokens the whole tool set costs.

What it does

Ten real rulesNot style: the checks that actually change call behaviour.
Score per tool setErrors, warnings and the token cost of the schemas.
Suggested rewritesA description that names the required input.
Context costWhich tool definitions eat the context of every request.

Usage

Lint a filetool-schema-lint tools.json
From a pipetool-schema-lint --stdin < tools.json
With rewritestool-schema-lint tools.json --suggest

How it works

  1. Every tool is scored against the rule set, with duplicates detected across the list.
  2. The token estimate of each schema is added up — that is the part people are surprised by.
